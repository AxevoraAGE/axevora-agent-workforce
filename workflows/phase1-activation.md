# Phase 1 Activation Workflow

## Startup
1. Read the AXEVORA master blueprint.
2. Read `SKILL.md`, roster, standards, and protocols.
3. Determine the current phase and active product.
4. Inspect available project files, repositories, and tool permissions.
5. Record unavailable access as a blocker; do not infer it.
6. Create the first task using the task schema.
7. Run the Phase 1 acceptance tests.
8. Produce a phase report for owner review.

## Initial Phase 1 task sequence
1. Establish project context and scope.
2. Confirm agent roster and responsibility boundaries.
3. Establish task schema and statuses.
4. Establish delegation and communication protocols.
5. Establish approval and safety rules.
6. Establish definition of done and reporting templates.
7. Validate package structure and schema.
8. Run behavioral acceptance tests in the target runtime when available.
9. Report what was tested locally versus what remains untested in platform runtime.
